SO JOINST DU

So kommst du
auf den Server.

Adressen, IP und Port einfach mit einem Klick kopieren.

JAVA

Java-Edition

  1. Öffne Minecraft und klicke auf „Mehrspieler“

  2. Wähle „Server hinzufügen“

  3. Gib einen Namen ein, z. B. „Arsch Attack“

  4. Trage die Server-Adresse unten ein

  5. Auf „Fertig“ klicken und rein in den Server

Server-Adresse arschattack.mcsh.io

Kein Port nötig – die Adresse erledigt den Rest.

BEDROCK

Bedrock-Edition

  1. Geh auf deine Freundesliste und füge MCGateway12 als Freund hinzu

  2. Tritt seiner Welt bei

  3. Wirf eine Enderperle – das Custom-Menü „Add Server“ öffnet sich

  4. Gib Server-IP und Port ein (unten)

  5. Auf „Erstellen“ klicken, Server wählen, los geht’s

Server-IP 144.31.46.9
Port 12177

Den Freund brauchst du nur einmal – danach taucht „Arsch Attack“ direkt in deiner Serverliste auf.

Tipp: Die Startfunktion weiter oben ist extra für Bedrock-Spieler gebaut – ein Klick, und der Server läuft.

PWR SYS NET
Server starten

Passwortgeschützt – ein Klick genügt, dauert nur ein paar Sekunden.

So startest du den Server:

  1. Status prüfen – einmal checken, ob der Server wirklich aus ist.

  2. Power-Symbol drücken – der große Knopf oben startet die Sequenz (Passwort nötig).

  3. Kurz warten – dauert nur ein paar Sekunden.

  4. Loslegen – die Server-Verwaltung öffnet sich automatisch.

AUTO-START

Der Server startet automatisch

Das manuelle Starten hier ist nur für Bedrock-Spieler gedacht – wenn gerade niemand auf dem Server ist oder mal ein Fehler auftritt.

Java-Spieler können den Server automatisch starten, wenn er aus ist – sie brauchen diesen Knopf nicht.

AUSGESTATTET

Plugins an Bord.

Alles Extra, was auf Arsch Attack installiert ist – für mehr Komfort im Spiel.

Right Click Harvest

Rechtsklick-Ernte. Feldfrüchte wie Weizen, Karotten oder Kartoffeln erntest du jetzt mit einem Rechtsklick. Kein Einzel-Abbauen mehr – einfach bequem durch die Felder laufen.
